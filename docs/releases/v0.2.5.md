# SpokenLog 0.2.5, build 17

A calmer phone layout, settings in plain words, and sharing the audio together with the transcript. Earlier release files and tags are retained. 0.2.3 and 0.2.4 offer this update in the app.

## New

- **Share audio with the transcript.** The share menu now offers the transcript only, the transcript with times, or the recording plus a timed transcript (.txt) as two files, for KakaoTalk, Telegram, ChatGPT and other apps. Files are named after the recording.
- **Phone layout:**
  - The screen starts with its name ("Recordings" or "Calendar") and three icons: calendar, import, settings.
  - One floating Record button; while recording, the bottom shows the time with pause and stop. Recording continues when you leave the app.
  - Rows show the title, a short date such as "Today 17:44", the first line of the transcript and the length.
  - A recording opens with a music-player style control (back 10 s, play, forward 10 s, speed) and one row of Edit, Copy, Share and Export.
- **Settings in plain words.** Each row shows its current state (for example "This phone · SenseVoice · Auto detect", "Not connected"). Speech settings ask "Where should it run?" and describe each model in one line.
  - Choosing an on-device model downloads it right away, and turning on speaker separation downloads its model.
  - Dialogs and sheets use a white background.
- **README:** a chart compares the speech models on Korean speech (mistakes and speed) and shows where each runs.

## Fixes

- **Phone search** keeps the keyboard when a letter leaves no results.
- **Android Back** leaves an open collection or multi-select before closing the app.
- **Empty Favorites, Trash and collections** say so instead of "No recordings yet".

## Verification

- Shared Flutter tests: 204 passed, optional native-inference tests skipped. Static analysis: no errors or warnings.
- Android 15 emulator: search, Back, sharing (the share sheet received two files named after the recording), recording with pause, resume and stop, background recording, settings, automatic model and speaker-model downloads.
- Windows 11: this source built and ran with existing recordings; settings and speech settings shown.
- Model chart: ten Korean sentences (67 s, synthetic voice) through each model on a 10-core PC with sherpa-onnx 2.0.3.
- GitHub Actions built and tested the Windows and Android release targets from this source.

Not established for this release: a physical Android device, receiving shared files in KakaoTalk, Telegram or ChatGPT, and iOS or macOS builds of this source.

## Distribution and device limits

Android still uses development signing, with the same key as earlier releases so it updates in place. Windows binaries are unsigned. macOS and iOS stay on 0.1.3 until their next build.
