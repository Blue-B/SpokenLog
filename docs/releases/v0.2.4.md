# SpokenLog 0.2.4, build 16

Fixes missing syllables in Korean local Whisper transcripts, adds Whisper Turbo on PCs and tidies the local models screen. Earlier release files and tags are retained. 0.2.3 offers this update in the app.

## New

- **Whisper Turbo on Windows and macOS** (about 1.04 GB, Settings > Local models). On a 30-second Korean clip it was as fast as Whisper Small on a 10-core PC and was the only local engine with no wrong words. Phones do not list it.
- **Choosing an engine** in the README shows which engine to use on Android, iPhone, Windows and macOS.

## Fixes

- **Korean Whisper transcripts kept every syllable.** The speech engine (sherpa-onnx) is updated from 1.13.8 to 2.0.3. The old version dropped Korean syllables with every Whisper size, for example "회의를" became "회를" and "피드백을" became "피을". Transcribe again to fix earlier local Whisper transcripts.
- **SenseVoice subtitle lines** break between words instead of inside one (for example "완성되었 / 고").
- **Faster local transcription on PCs:** up to 8 CPU threads instead of 4 (about 28% faster for Turbo in the same test). Phones still use 4.
- **Local models screen:** each model shows its name, then the description, then the button, so phone screens no longer squeeze the text into a narrow column.

## Verification

- Shared Flutter tests: 200 passed, six optional native-inference tests skipped. Static analysis: no errors or warnings.
- Real inference with sherpa-onnx 2.0.3 on Linux: Whisper Tiny, Base, Small and Turbo and SenseVoice transcribed a long English recording completely, and a Korean regression check passed (it fails on 1.13.8). The Korean check and SenseVoice also passed on Windows with the Windows libraries.
- Android 15 emulator: SenseVoice downloaded and transcribed a Korean file; the local models screen lists no Turbo on the phone.
- GitHub Actions built and tested the Windows and Android release targets from this source.

Not established for this release: a physical Android device, Turbo speed on typical laptops, and iOS or macOS builds of this source.

## Distribution and device limits

Android still uses development signing, with the same key as earlier releases so it updates in place. Windows binaries are unsigned. macOS and iOS stay on 0.1.3 until their next build.
