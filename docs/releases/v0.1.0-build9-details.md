## Changes

- Split long local audio before inference. Previously, Whisper read only the first 30 seconds of a file; SenseVoice also now processes bounded windows with time offsets.
- Offer Whisper Tiny, Base and Small multilingual INT8 models, approximately 104, 161 and 375 MB. Preserve Tiny's existing model directory.
- Synchronize the saved Whisper size after saving settings and immediately before transcription. A regression test fails without this repair and passes with it.
- Produce approximate local Whisper subtitle segments from pauses and the audio pieces' start/end times. The downloaded ONNX models do not provide word timestamps.
- Remove Moonshine from the engine picker. Old Moonshine preferences fall back to SenseVoice; old downloaded files are not deleted.
- Add Settings → About → Open-source licenses, including Whisper and SenseVoice model notices.

The Windows ONNX Runtime repair and earlier data-management behavior remain. See the [historical build 8 details](v0.1.0-build8-details.md) for those changes.

## Recording and subtitle limits

There is no explicit app recording-duration quota. That does not mean unlimited recording:

- 16 kHz mono 16-bit PCM uses about 115 MB per hour.
- Conventional WAV's roughly 4 GB limit corresponds to about 37 hours per file. This is a theoretical format ceiling, not a tested safe recording duration.
- Free space, battery, OS suspension, interruptions and device resources can impose earlier limits.
- Local transcription still reads the whole WAV into memory, even though inference is windowed.

Whisper cue times are approximate audio-window boundaries, not word alignment. Pauses normally produce short pieces, but fallback behavior can use longer windows. No character-per-line, reading-speed or editorial sentence-boundary rules are enforced. SRT export was checked; importing it into Premiere Pro was not.

## License review

The app remains [AGPL-3.0-only](../../LICENSE). Model weights are downloaded separately and are not included in the application packages. Their terms are independent of the app and engine licenses.

- [OpenAI Whisper](https://github.com/openai/whisper/blob/main/LICENSE): MIT. The app includes the OpenAI copyright and MIT text.
- [SenseVoice](https://github.com/FunAudioLLM/SenseVoice): model weights use the FunASR Model Open Source License 1.1, not simply the engine's Apache license. The app includes its license text, model name and Alibaba attribution. This is a custom agreement with conditions beyond attribution, including conduct and revision provisions; it should not be treated as equivalent to MIT or Apache-2.0.
- [3D-Speaker](https://github.com/modelscope/3D-Speaker): the repository and ModelScope ERes2Net model metadata report Apache-2.0.
- [pyannote segmentation 3.0](https://huggingface.co/pyannote/segmentation-3.0): identified as MIT, but direct access to the original gated card and some conversion documentation was unavailable during this review. The in-app speaker-model notice contains labels and source links, not full copies of all speaker-model license texts. Conversion provenance and any additional notice obligations remain incompletely verified.
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx): Apache-2.0. The engine license does not replace model-specific licenses.
- Direct Dart dependency license files inspected were MIT/BSD/Apache-2.0; transitive `dbus` uses MPL-2.0. Some Flutter SDK test/web-plugin packages lacked individual license files in the scan. This was not an exhaustive legal audit of every packaged native binary and transitive component.

Moonshine Tiny KO was removed because the non-English model's community license has additional commercial conditions, including a US$1 million annual revenue threshold. Removing that option does not grant new rights to any old downloaded model files.

These findings are not blanket legal clearance for commercial redistribution. Review the original terms and remaining speaker-model/native-component gaps before redistributing models or changing the app's licensing.

## Signing and unverified behavior

- Windows packages are not publisher-signed. Android uses the same development certificate as build 8, not production-store signing.
- macOS is ad-hoc signed and not notarized. The ordinary-user download/Gatekeeper approval flow remains unverified.
- The device IPA is unsigned. Real iPhone installation, Apple Account signing/renewal and physical-device execution remain unverified.
- No physical Android/iOS, continuous microphone, Bluetooth, background/lock/interruption or audible-playback validation was completed for this refresh. The Android emulator ran without audio input.
- Live cloud transcription and speaker-separation inference were not revalidated in this refresh.
- Some imported WAV details stayed at “Checking duration” / `--:--` despite successful transcription. An import notification still appeared in Korean in English mode. These UI issues are unresolved.
- Model completeness checks use expected file sizes with a tolerance, not cryptographic checksums. This release does not claim model-download integrity hardening.
- The full interactive uninstall cancellation/selected-deletion paths, macOS removal helper approval flow, cloud timeout handling and atomic metadata/checkpoint writes remain outside this validation.
