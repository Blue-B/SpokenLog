# SpokenLog 0.2.1, build 13

Shows how far cloud transcription has got instead of a long "Preparing" wait. Earlier release files and tags are retained.

## New

- **Transcription progress.** Groq and Cloudflare transcription now report each chunk as it starts, with the chunk number, a percentage, a progress bar and the elapsed time ticking every second. Before, the first 10-minute chunk showed "Preparing" until it had finished.

## Verification

- Shared Flutter tests: 187 passed, four optional native-inference tests skipped. Static analysis: no errors or warnings, 39 informational findings (mostly deprecation notices new in Flutter 3.50).
- Built with Flutter 3.50.1.
- GitHub Actions built and tested the Windows and Android release targets from this source.

Not established for this release: the progress display in a running app on a device. Treat it as untested until confirmed.

## Distribution and device limits

Android still uses development signing, with the same key as earlier releases so it updates in place. Windows binaries are unsigned. macOS and iOS stay on 0.1.3 until their next build.
