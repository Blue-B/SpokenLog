# SpokenLog 0.2.2, build 14

Makes transcripts easier to send to other apps and fixes a few things that got in the way on phones. Earlier release files and tags are retained.

## New

- **Share transcripts.** A Share button next to Copy opens the system share sheet, so a transcript can go straight into ChatGPT, a chat app or notes. Choose **Text only** or **With timestamps** (`[00:04] ...` before each line, with speaker names when speaker separation ran). Android, iPhone and macOS; on Windows use Copy or Export.
- **Export tells you where the file went.** After saving a TXT, SRT, VTT or JSON export, the message shows the location, for example `Download/meeting.txt`.

## Fixes

- **Calendar on phones.** Tapping a recording under a calendar date now opens that recording, instead of switching to the Records tab.
- **". . . ." before the text.** Whisper sometimes answers silence and noise with lines that are only "." or "..."; those lines are now dropped. This applies to new transcriptions; transcribe again to clean an existing one.
- **"Duration unavailable".** On Android, recordings kept in their original format (for example an M4A that could not be converted to WAV) now show their length from the file's own information.

## Verification

- Shared Flutter tests: 190 passed, four optional native-inference tests skipped. Static analysis: no errors or warnings.
- On an Android 15 emulator: importing an M4A showed its length, a calendar tap opened the recording, both share options opened the share sheet with the expected text, and a TXT export reported `Download/<name>.txt`.
- GitHub Actions built and tested the Windows and Android release targets from this source.

Not established for this release: a physical Android device, the dot cleanup against a live Groq response (checked with recorded-style test data), and the duration of an M4A that stays unconverted (the emulator converted the test file).

## Distribution and device limits

Android still uses development signing, with the same key as earlier releases so it updates in place. Windows binaries are unsigned. macOS and iOS stay on 0.1.3 until their next build.
