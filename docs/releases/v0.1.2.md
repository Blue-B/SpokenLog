# SpokenLog 0.1.2, build 10

A maintenance release for local data safety and cloud-request handling. It continues the build 9 source line, including long local transcription and Whisper Tiny, Base and Small selection. Existing v0.1.0 and v0.1.1 tags and files are retained.

## Changes

- Save recording and collection metadata to a staged file before replacing the destination. Recording checkpoints and the final stopped state are written in order. Failed writes do not permanently block later saves.
- Store and load transcript text, segments and speaker labels from one JSON snapshot. TXT remains a compatibility copy. Older TXT-only recordings still load, and a failed TXT copy does not discard the committed JSON transcript.
- Limit each Groq or Cloudflare request to 10 minutes, including upload and the complete response body. Close the connection on completion or timeout. Timeout errors use the existing network-error and alternative-transcription flow. This is a per-audio-part limit, not a limit on the full recording.
- Read the release version from source when packaging Windows and Apple files, rather than requiring 0.1.0. Keep the existing app identifier and data locations.
- Update download and installation guidance to identify this version and distinguish it from the separate older v0.1.1 source line.

## Verification scope

The storage and request changes passed 165 shared Flutter tests, with four optional native-inference checks skipped because their runtime fixtures were not configured. The final focused storage and network checks passed 25 tests. Static analysis reported no errors or warnings and 18 existing informational findings. These are source-test results, not proof of recording or transcription on every device.

New regression checks cover inconsistent TXT/JSON reads, preservation of the previous TXT when JSON replacement fails, committed JSON survival when the TXT copy fails, legacy TXT fallback and complete-file reads during replacement. Local HTTP-server checks cover responses stalled before headers or during the body; client ownership and both providers' timeout-error mapping are also checked. The Apple packaging version parser accepts 0.1.2 and rejects malformed versions.

Platform compilation and final archive checks are recorded in the published release description once the corresponding files have been built and verified. Do not infer a completed platform build from this source document alone.

## Limits

- File replacement prevents partial-file overwrites during ordinary writes. It does not guarantee recovery from every filesystem or power failure. Keep backups.
- Local transcription still requires WAV. Large WAVs are read into memory, and local Whisper subtitle times are approximate audio-window boundaries rather than word alignment.
- Cloud transcription uploads audio to the selected provider and may incur provider charges. A timeout does not establish that the provider did not process or bill a request.
- This release does not add production Android signing, Windows publisher signing, macOS notarization, App Store or TestFlight distribution.
- Earlier build 9 runtime results are documented [separately](v0.1.0-build9-details.md). They are not new physical-device, microphone, background, Bluetooth or interruption tests of 0.1.2.
- Model-download checksum hardening, remaining speaker-model license provenance and the existing imported-duration and localization issues are outside this update.
