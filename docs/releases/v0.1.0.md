# SpokenLog v0.1.0

The displayed version remains **0.1.0**. All five application packages contain **build 7**. Android and Windows use app-code commit `2214b8ff564b4c907d425be95c700aba8e999fa6`. Apple packages were rebuilt at `ce00e3eefbc6bbcbdd068ec0529e998931187cec`, which adds only macOS packaging configuration and its regression checks; shared app code is unchanged. Android and Windows were built locally. Apple packages were rebuilt and verified inside the existing manual Codemagic remote session. GitHub Actions was not used because its account budget blocked jobs from starting.

## Build 7 repairs

- Preserve microphone, network and file-selection entitlements in the final macOS signature. Build 6's last signing step removed them and prevented the native file picker from opening. Release checks now inspect the extracted ZIP's actual signature and entitlement values.
- Keep the existing nonsandboxed desktop data locations. This does not migrate recordings, models or credentials into a new sandbox container.
- Use Flutter's supported macOS Skia renderer setting after corrupted text/icons appeared with MetalSDF during remote M2 restart tests. The final rebuilt ZIP displayed correctly before and after restart. iOS renderer settings are unchanged.
- Save display-language changes before closing the dialog. A secure-storage failure keeps the dialog open with a localized, retryable error and does not expose raw errors or secrets.

## Retained build 6 changes

- Fix clipped recording-language labels and long dropdown values in narrow or large-text settings dialogs.
- Add select-all/deselect-all for the filtered recording list. Hold and drag to select a range, with edge scrolling and reversal support. A separate recording menu remains available. Native file-picker gestures are unchanged.
- Show compact Groq and Cloudflare free-limit guidance before credential entry, with official key/account setup and limit links. Expand details when needed; copy the URL if a browser cannot open. These figures are published baselines, not the account's remaining quota.
- Add Settings → Storage management with folder sizes and separate choices for recordings/transcripts/Trash, downloaded models, and local credentials/preferences. Nothing is selected by default; deletion requires another confirmation. Export important recordings before deleting them.
- Prevent concurrent current-version desktop instances from accessing data during cleanup. In-app cleanup is blocked while recording, importing or transcribing. Close older app versions too.
- Add a Windows installer. Interactive uninstall opens the data-management screen; Cancel stops removal, and silent uninstall keeps user data. Deleting a portable ZIP folder does not run cleanup.
- Include `Uninstall-SpokenLog.command` in the macOS ZIP. Keep it next to the app or put the app in `/Applications`. It opens the opt-in data screen and asks again before moving the app to Trash. Direct Finder deletion bypasses this helper and keeps data.

Cleanup does not remove exports, imported originals outside the app folder, OS/cloud backups or provider-issued API keys. Deleting local credentials does not revoke those keys. Minor OS/container metadata can remain. See [desktop removal details](https://github.com/Blue-B/SpokenLog/blob/main/docs/desktop-removal.md).

## Retained build 5 fixes

- Cap temporary WAV upload parts at 24 MiB, including the header and complete audio frames. High-rate stereo imports no longer produce oversized Groq requests.
- Use actual WAV duration for Cloudflare chunk offsets, preserving trailing silence in timestamps.
- Stop the recorder when setup fails after microphone capture begins. Clear active-session state even when final metadata persistence fails.
- Create unique recording directories and reject overlapping starts, preventing rapid recordings from overwriting each other.
- Repair supported interrupted PCM WAV headers before recovery, retaining a `.recovery-original` copy. Do not recover a recording that is still active.
- Clean up prepared temporary files when splitting fails.
- Keep the existing file-based macOS Keychain option. Credentials remain in Keychain, not plaintext files. An inaccessible or locked Keychain still requires its owner's normal unlock/authorization; the app does not bypass it.

## Recording playback and transcription

- Recording details subscribe to player position, duration, play/pause state, and recording-data changes instead of displaying a stale snapshot.
- Progress uses the native playback position, including seeking, and a single-file recording uses the player's actual duration.
- Transcription progress, refreshed titles/transcripts, and errors remain visible inside the recording detail sheet.
- Missing Groq or Cloudflare credentials open an input dialog above the current recording. Cancel returns to the same recording; saving can continue the requested transcription.
- Repeated transcription taps do not stack credential dialogs or start duplicate requests. Credential storage failures stay in the dialog and do not display secret values.
- Large-text playback controls wrap instead of overflowing. Rename dialogs retain their input state safely through dismissal.

## Mobile navigation and settings

- The gear opens a settings hub with direct Groq API key, Cloudflare credentials, local-model management, transcription/audio-language, and display-language entries.
- Fixed All / Favorites / Collections / Trash scopes replace the growing horizontal collection-chip row.
- Collections open a vertical folder browser with explicit open/back/create/rename/delete controls.
- The calendar uses a compact month or week selector with a full-width selected-day agenda. Recording titles have two lines and transcript previews up to four lines; long Korean text is no longer squeezed into a one-character day-cell column.
- Changing the displayed month updates the selected date in that month.

## Local recognition and automatic language selection

- Moonshine KO remains a Korean-only engine, not a language detector. Selecting Auto requires explicit confirmation to transcribe that recording as Korean; the saved Auto preference is not silently changed.
- SenseVoice supports automatic detection within its supported languages. Local Whisper Tiny supports automatic detection, but explicit Cantonese (`yue`) is rejected because the bundled model lacks that language token.
- All three local engines check WAV input and reject unreadable, empty, malformed or unsupported audio before passing it to the native decoder.
- Android native libraries for arm64-v8a, armeabi-v7a and x86_64, and the iOS arm64 framework, were checked. Initial model downloads are required; local transcription does not accept imported MP3/M4A directly.

## Android installation notice

Build 7 uses the same development signing certificate as the preceding repaired builds 3, 4, 5 and 6. Much older CI-built APKs used another certificate and may refuse an in-place update. Export/back up recordings and transcripts before considering removal of such an older installation, because uninstalling can delete local app data. Production/store signing is not configured.
