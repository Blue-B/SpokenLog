# SpokenLog v0.1.0

First release. The release version remains **0.1.0**; the replacement mobile packages use internal build number **3**.

## Downloads

| Platform | File | Installation |
| --- | --- | --- |
| Windows x64 | `SpokenLog-Windows-x64.zip` | Extract the entire ZIP, then run `SpokenLog.exe`. |
| Android | `SpokenLog-Android.apk` | Download the new APK and install it. See the signing notice below. |
| macOS | `SpokenLog-macOS.zip` | Extract and open the app. This build is ad-hoc signed, not Apple-notarized. |
| iOS / iPadOS | `SpokenLog-iOS-unsigned.ipa` | **Unsigned device build. Apple signing and provisioning are required before installation. This is not a tap-to-install App Store or TestFlight download.** |

`SHA256SUMS.txt` contains the checksums of all four downloads.

## Mobile package corrections

- Android: the generated launcher class, Gradle namespace, application ID, and manifest now agree on `io.github.blueb.spokenlog`. This corrects the launcher-package mismatch in the original APK.
- Android: rebuilt in release mode with version name `0.1.0` and version code `3`, using the checked-in dependency lockfile. The APK includes arm64-v8a, armeabi-v7a, and x86_64 native libraries.
- iOS: uses the successfully compiled Apple device payload with the corrected `io.github.blueb.spokenlog` bundle identifier. Its version metadata was repackaged as `0.1.0` / build `3`; executable payloads were not changed or recompiled during this refresh.
- Windows and macOS: the existing v0.1.0 downloads are retained unchanged.

## Verification for this refresh

- Local Android release build succeeded.
- All 30 existing Flutter tests passed.
- Static analysis reported no errors or warnings; 24 existing informational lint notices remain.
- APK signature verification passed. The launcher class was verified in the compiled DEX, not only in source configuration.
- Both mobile archive structures and the iOS version, bundle identifier, microphone description, and background-audio setting were checked.
- iOS repackaging changed only `Payload/Runner.app/Info.plist`; all other archived payload bytes were checked against the successful source build.
- Android and iOS physical-device execution were **not** tested during this refresh.

## Android signing notice

This APK uses the current local development signing key, not a configured Play Store release-signing setup. Its signer differs from the original CI-built APK, so an existing installation signed by the old key cannot be updated in place. Before uninstalling an old installation, export or back up any recordings and transcripts: uninstalling may remove local app data. Use the APK from this release rather than an earlier downloaded copy.

## Highlights

Local-first recording library; local or cloud transcription; local speaker diarization; editable transcripts and speaker names; batch transcription; background/screen-off recording where supported by the operating system; interrupted-recording recovery.
