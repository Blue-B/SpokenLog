## Changes

Build 9 (0.1.0+9):

- Process long WAV files in pieces instead of losing audio after Whisper's first 30 seconds.
- Choose local Whisper Tiny, Base or Small. Fix saved model selection when starting transcription.
- Export local Whisper subtitles using approximate pause-based timing.
- Remove Moonshine from the available engines and add model license notices in Settings.

Whisper subtitle times are not word-accurate, and Premiere import has not been tested. There is no app-imposed recording timer, but storage, WAV size, memory and device limits still apply.

Back up important recordings before updating.
