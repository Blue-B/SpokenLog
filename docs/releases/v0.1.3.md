# SpokenLog 0.1.3, build 11

A maintenance release for WAV duration, small-screen layouts and settings feedback. Earlier release files and tags are retained.

## Fixes

- Read WAV duration when importing a file and save it with the recording. Previously imported and legacy WAV files with missing duration now show their length when the library loads, without rewriting the existing audio or metadata. Other formats can still have unavailable duration.
- Let mobile navigation and library headers scroll away so recording cards remain reachable on small screens with large text. Preserve long-press range selection and edge scrolling.
- Make quick speech settings scrollable, including its Apply button, on short landscape screens. Allow the empty-transcript panel to grow with large text.
- Show a safe error message when secure storage rejects a settings write. Quick settings stay open and allow retry; raw error text, which may contain credentials, is not shown.
- Translate the observed English-interface gaps in automatic language detection, unnamed recording titles, the recording-rename dialog, playback controls and recording/import/export notices. Allow long labels in the compact recording menu to wrap instead of overflowing. This is not a claim that every message in the app has been translated.

## Verification

The core fixes were exercised in the candidate built from source commit `44022e7cf7e1731725c6046f4a8820b5d69aa6b6`, as recorded below. Its package versions, identities, required runtime files, archive integrity and checksums were checked; the extracted Windows files and installed Android APK matched the candidate archives. The final release is rebuilt after the remaining rename-dialog and compact-menu corrections. Its exact source commit, package verification and final smoke checks are recorded on the [release page](https://github.com/Blue-B/SpokenLog/releases/tag/v0.1.3).

The candidate's shared Flutter suite passed 173 tests, with four optional native-inference checks skipped because their fixtures were not configured. Its Windows regression set passed 49 tests; three Apple packaging-tool tests passed. Static analysis reported no errors or warnings and 18 existing informational findings. The final rename regression also checks the English and Korean labels, hint, save operation and compact-menu layout; final test totals are recorded on the release page.

These checks do not cover every screen size.

## Remaining limitations

- Physical microphone speech capture and audible speaker output were not validated for this release. Playback checks above establish UI state and position changes, not that sound was heard.
- Live cloud requests, every model size, speaker separation, batch-operation combinations and complete installer/removal flows were not all exercised in this candidate check.
- Other formats can still have unavailable duration, and local transcription still requires WAV. Existing format, memory and subtitle-timing limits remain; see [features and formats](../features.md).

Do not treat this platform matrix as a claim that every feature works on every device.

## Distribution and device limits

Android still uses development signing. Windows binaries are unsigned. The Mac app is ad-hoc signed and not Apple-notarized. The supplied iOS IPA remains unsigned and requires compatible signing and provisioning; it is not an App Store or TestFlight release and cannot be installed by tapping the file.

No iPhone/iPad or physical Android device is available in the current verification environment. Physical-device microphone quality, Bluetooth, screen-off/background recording, calls and interruption handling are not established by emulator or package checks. Cloud transcription uses the selected provider and can incur charges; this update does not establish a new live-provider verification result.
